基礎知識(休憩・負荷・サプリ・食事など)
筋トレや運動の休憩
  • 筋肥大のための筋トレや運動のパフォーマンスを効果的に高める最適な休憩時間とは何分か？
    • セット間の休憩時間: 3分間の休憩が最も効率の良い筋トレができる。5分も休むと筋肉が冷えて休憩の意味がなくなる。1分の休憩だと筋力が疲れている状態で力が十分に入らず効果が下がる。2分くらいからが効果が出てくる最低ライン
    • 筋トレの内容をスーパーセットにしてしまう(上半身と下半身のメニューを交互にこなすと時短)
筋トレ効果を高める 正しい負荷や負荷の感覚
  • 筋トレの負荷に対するツラさを測る方法は何という？
    • RPE(rate of perceived exertion): 筋トレのキツさを主観で計測する方法
    • RPE判断基準: 1〜4点=楽勝レベル(ほとんど努力不要) / 5〜6点=後4〜6回はできそう / 7点=後3回できると自信を持って言える / 7.5点=後2回できるが3回いけるかも / 8点=後2回できるかも / 8.5点=後1回できると自信を持てるが2回いけるかも / 9点=後1回できるかも / 9.5点=もう1回もできないがちょっとだけいけるかも / 10点=もう1回も絶対に無理
  • 1セットあたり6〜20回の範囲なら筋肥大の結果は同じ
    • 1セットの回数が6〜20+の範囲でRPEが7より上であれば、筋肉の発達にそんな差が出ない
  • ピリオダイゼーション
    • ピリオダイゼーションとは何か？
      • 短い期間のなかで負荷やボリュームを変えるトレーニングで、筋サイズより筋力が上がりやすい
    • ピリオダイゼーションを基にした筋トレ方法とは？
      • ベースの考え方: 1週目は1RMの70%で8回を5セット / 2週目は1RMの75%で5回を5セット / 3週目は1RMの80%で3回を5セット / 4週目は1週目より少し重い負荷で8回を5セット
      • デイリー・ピリオダイゼーション: 1週間の中で最大まで重さを上げたら月曜日からまた低負荷でやり直す。毎週月曜=1RMの60%をへとへとになるまで計5セット / 毎週水曜=1RMの75%を計4セット / 毎週金曜=1RMの90%を計3セット
  • RMとは何か？
    • RM(repeating maximum): 1回の動きで上げられる限界の重量
サプリメント
  • クレアチン
    • 筋力を増やすために使用するクレアチンは、いつ取ると良いか？
      • クレアチンは筋トレ後のほうが結果が出やすい(トレーニング後に飲んだほうが筋肉量は増える。前:0.9kg増、後:2.0kg増。筋力もトレーニング後のほうが増える/ベンチプレス1RM)
      • トレーニング後はインスリン感受性が高まっていて、糖質と一緒にクレアチンを補給するタイミングとしてはありかも
有酸素運動
  • 1日あたり何分の有酸素運動が良いか？また、やりすぎるとどうなるか？
    • 15分でOK。45分以上だとストレスホルモンが出すぎてしまう
    • 運動をさぼると10日で悪くなる(脳の血流が下がり、能率が下がる)
  • 筋力を高める運動手順は？また、それはいつすれば良いか？
    • 夕方に有酸素運動→筋トレの順で筋力が最大になる
HIIT(High-intensity interval training)
  • HIIT(間欠的運動)とは、高強度(High Intensity)の運動を休憩を挟んで(Interval)行うトレーニング(Training)のこと
    • HIIT WB(自重トレーニング): 全力で4種目を4分間。1種目につき20秒(全力)⇔10秒(休憩)。1バービー 2マウンテンクライマー 3スクワットスラスト 4ジャンピングジャック。心肺機能が高まり、疲労でよく眠れる/連続して仕事しても疲れにくい
  • ノルウェー式HIIT
    • メリットは？
      • 細胞レベルで若返る。ミトコンドリアの性能が49%アップ(18〜30歳)、69%アップ(65〜80歳)。インスリン感受性も大きく改善。集中力や活力の向上にもつながる。週3回で細胞内の老化物質が処理され新しいタンパク質として生まれ変わる
    • HIITが体を若々しく保ってくれる理由は？
      • 老化の原因の一つは損傷したタンパク質が細胞内に残ること。HIITには細胞内の損傷タンパク質の蓄積を防ぐ効果がある
    • やり方の手順は？
      • 0. 5分間のウォーミングアップ(ランニングマシン・サイクリング・スクワットでもOK) → 1. 4分間全力運動(バービージャンプ、最大酸素摂取量85〜95%) → 2. 3分間の軽い運動(ジャンプ・歩く・軽いジョギング) → 1⇔2をセットで4回繰り返す → 最後に5分間のクールダウン
リーンゲインズとは何か？
  • 体内のミトコンドリアに活を入れる
  • 1日のうち8時間は何でも食べて良く、残りの16時間は何も食べない
食事法
  • IPF(インターミッテント・パーシャル・ファスティング)
    • ①週に3日だけ、1日の必要カロリー(TDEE)から30〜40%引いた食事をする ②プチ断食の日は最低でも体重1kgあたり1gのタンパク質を摂る
  • 朝起きたら、一番最初にカフェインとテアニン、チロシン、ロディオラを飲む(by DaiGo)
モテる体型
  • 体脂肪
    • 男性で腹筋が浮き彫りになる体脂肪率は何%か？また下がり過ぎるデメリットは？
      • 男性8〜10%、10%前後で良い。※10%を切るとテストステロンが下がる
  • 体型
    • 男性: 大胸筋がありお腹が引き締まっている
    • 女性のバストの魅力: 大きさでなく、張りと丸み

背筋
  • 中部僧帽筋
    • 筋肥大が効率的に狙える筋トレ方法トップ3: ①ベントオーバーロウ ②IYTレイズ ③インバーテッドロウ
      • ベントオーバーロウのやり方: 肩幅より少し狭めで立つ。スネは垂直に。バーは小指と薬指で握る(親指は添えるだけ)。背中はまっすぐ前傾(床に対して35〜45°)。広背筋なら足の付け根に、僧帽筋ならみぞおちにバーを引く。腕を伸ばしきらずに肘を持ち上げる意識で
    • 逆効果の筋トレ方法(中部僧帽筋への効果が低かったもの): 逆手の懸垂・順手の懸垂・ラットプルダウン
  • 僧帽筋下部: ①IYTレイズ ②ベントオーバーロウ
  • 広背筋: ①順手の懸垂 ②逆手の懸垂
  • 棘下筋: ①IYTレイズ ②ベントオーバーロウ ③インバーテッドロウ
  • 脊柱起立筋: ①ベントオーバーロウ
胸
  • 筋肥大が効率的に狙える筋トレ方法トップ3: ①バーベルベンチプレス(平均EMG100) ②ペックデックマシン(平均EMG98) ③前傾ケーブルクロスオーバー
腕
  • 力こぶ: ①コンセントレーションカール ②ケーブルカール ③チンアップ
  • 二の腕(上腕三頭筋): ①トライアングルプッシュアップ ②キックバック ③ディップス ※ダンベル種目は1RMの70%負荷で行う
肩
  • 三角筋前部: ①ダンベルショルダープレス ②ダンベルフロントレイズ
  • 三角筋中部: ①45度インクラインロウ ②ベントアーム・ラテラルレイズ ③ケーブル・レイズ
  • 三角筋後部: ①シーテッド・リア・ラテラルレイズ ②45度インクラインロウ
尻
  • 大臀筋: ①クアッドプル・ヒップ・エクステンション ②フォーウェイ・ヒップ・エクステンション ③スクワット
  • 中臀筋: ①クアッドプル・ヒップ・エクステンション ②ステップアップ ③ランジ
足
  • 大腿二頭筋(ハムストリング・太ももの裏): ①ケトルベル・スイング ②プローン・レッグカール ③片足ルーマニアン・デッドリフト
  • 半腱様筋(太ももの内側): ①リバース・ヒップレイズ ②バランスボール・ハムストリング・カール ③グルートハム・レイズ
  • 大腿四頭筋(太ももの筋肉): ①スクワット(足は肩幅でヒザは90度曲げる) ②レッグ・エクステンション ③ハック・スクワット
    • スクワットのフォーム: 足裏の重心は足の真ん中。爪先は30〜40°程度に外向ける。膝を外に開いてしゃがむ。しゃがんでも背中・骨盤は真っ直ぐのまま。お尻を後ろに出してヒップドライブを使う
  • 下腿三頭筋(ふくらはぎ): ①ドンキー・カーフレイズ ②片足カーフレイズ ③両足カーフレイズ
腹筋
  • 腹直筋上部(お腹の上): ①デクライン・ベンチ・カールアップ ②シットアップ ③バランスボール・クランチ ※普通にシットアップで良い
  • 腹直筋下部(お腹の下): ①デクライン・ベンチ・カールアップ ②バランスボール・クランチ ③キャプテン・チェア・クランチ ④ボートポーズ ⑤バイシクル・クランチ ※ベンチが使えるなら①が圧倒的に効果高い、自宅で器具がなければ④⑤
  • 外腹斜筋(脇腹): ①デクライン・ベンチ・カールアップ ②キャプテン・チェア・クランチ ③ボートポーズ
種目別フォーム解説
腕立て伏せ
  • 肩甲骨はがし腕立て: 0.肩甲骨を動かし両手を真上に伸ばす/戻すを繰り返す 1.体を支えるのは小指側 2.胸と手は常に一直線上 3.正面から見て肘は45度方向に曲げる 4.横から見て肘は30度位だけ曲げる ※胸じゃなく脇に効いていればOK
スクワット
  • 正しいフォームでスクワットを10回することで血行を正す(100回より10回のほうが効果が出る)
  • 手順: 1.足を肩幅ほどに開く 2.爪先は少し外側に向ける 3.息をゆっくり吸い始める 4.お尻を突き出すことで自然と腰を曲げる 5.膝が約90度に曲がったらキープする 6.息を吐きながら膝を軽く曲げた状態まで立ち戻る 7.3に戻る
  • 効果: インナーマッスルを鍛える/基礎代謝が上がる
